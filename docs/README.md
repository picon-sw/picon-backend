# PIC:ON Backend 개발 참고자료

본 디렉터리는 PIC:ON 백엔드 개발에 필요한 API 명세서, 데이터베이스 ERD 및 인프라 아키텍처 자료를 관리하기 위한 공간입니다.

백엔드 개발자는 기능 구현 전 관련 문서를 확인하고, 기존 프로젝트 코드 및 팀에서 합의한 정책과 비교하여 개발을 진행합니다.

## 디렉터리 구조

```text
docs/
├── README.md
├── api/
│   └── portfolio-images.md
├── erd/
│   └── erd.sql
└── infrastructure/
    └── architecture.png
```

## 문서별 설명

| 경로 | 설명 |
|---|---|
| `api/` | API별 Request, Response, Status 및 구현 검토사항 |
| `erd/` | 데이터베이스 테이블 및 관계 설계 참고자료 |
| `infrastructure/` | 서버, 데이터베이스, 스토리지 등 인프라 아키텍처 설계도 |

## 문서 활용 방법

1. 기능 구현 전 해당 API 명세서를 확인합니다.
2. ERD와 기존 Entity를 비교하여 데이터 구조를 확인합니다.
3. 인프라 아키텍처를 참고하여 외부 서비스 및 저장소 연결 방식을 검토합니다.
4. 기존 프로젝트의 공통 응답, 예외 처리, 인증 및 코드 컨벤션을 준수합니다.
5. 명세서에 미확정 사항이 있을 경우 팀원 간 협의 후 구현합니다.

## 유의사항

- API 명세서는 현재 2차 초안이며 일부 정책은 미확정 상태입니다.
- ERD는 설계 참고자료이며 실제 DB 스키마 및 JPA Entity와 차이가 있을 수 있습니다.
- 인프라 구성도는 설계 자료로, 실제 배포 환경과 다를 수 있습니다.
- 문서와 구현 내용이 다를 경우 임의로 수정하지 않고 팀원 간 확인합니다.
- 비밀번호, API Key, Secret Key 등 민감정보는 저장소에 업로드하지 않습니다.

## 문서 관리

문서 변경은 GitHub Issue 및 Pull Request를 통해 관리하며, 관련 팀원의 리뷰를 거쳐 `develop` 브랜치에 반영합니다.

기능 구현 코드와 문서 정비 작업은 가능한 한 별도 PR로 관리합니다.
